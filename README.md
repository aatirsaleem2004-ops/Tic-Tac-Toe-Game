🕹️ Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.
Play with a friend and see who wins first — X or O!

✨ Features

✅ Two-player mode
✅ Detects winner or draw automatically
✅ “Play Again” / Reset option
✅ Clean and modern UI
✅ Fully responsive (works on desktop & mobile)

🧠 Technologies Used

HTML5 – for structure

CSS3 – for styling and layout

JavaScript (ES6) – for logic and interactivity

🎮 How to Play

Open the game in your browser.

Player 1 starts with X and Player 2 with O.

Click on any box to make your move.

The game will announce the winner or a draw.

Click Reset to play again!
